Kriteria pemeriksaan: Dataset terbaca, target & metrik tepat, split tidak bocor, baseline dapat dijalankan dan tanggung
jawab anggota jelas.
Minggu 13 - Genetic Algorithm dan feature/variable selection
Fokus kerja: Implementasikan encoding chromosome, objective/fitness, selection, crossover, mutation,
elitism dan stopping criterion. Lakukan GA pada fitur/sensor/lag, lalu latih NN pada subset hasil GA dengan
protokol split tetap.
Deliverables yang diserahkan:
1. W13_GA_Progress.pdf: rumus fitness, hyperparameter GA, log konvergensi, fitur terpilih.
2. Kode GA, minimal bukti beberapa seed (sesuai sumber daya), convergence curve dan tabel fitur sebelum/sesudah.
3. Tabel Baseline NN vs GA+NN (metrik validasi, jumlah fitur, waktu komputasi); halaman GA dashboard.
Kriteria pemeriksaan: GA benar-benar melakukan pencarian; fitness dapat dipertanggungjawabkan; fitur tidak dipilih
berdasarkan test set; hasil dapat diulang.
Minggu 14 - PSO, Neural Network dan eksperimen pembanding
Fokus kerja: Definisikan particle, search bounds, pbest, gbest, velocity-position update dan stopping rule.
Tuning NN via PSO; bandingkan 4 konfigurasi dengan split, metrik dan anggaran evaluasi terdokumentasi.
Deliverables yang diserahkan:
1. W14_PSO_NN_Progress.pdf: search space, parameter PSO, kurva gbest, hasil utama.
2. Kode PSO dan training, logs, training/validation curves, checkpoint model & preprocessing pipeline.
3. Tabel empat model: fitur, hyperparameter, metrik dan waktu; dashboard beta Prediction dan Model Comparison.
Kriteria pemeriksaan: PSO melakukan optimasi riil, model dapat dimuat ulang, perbandingan tidak bias, klaim perbaikan
dibuktikan oleh data.
Minggu 15 - Fuzzy Inference, integrasi dan public deployment
Fokus kerja: Bangun FIS memakai input dan aturan yang relevan, lengkap dengan membership functions dan
inference/defuzzification. Hubungkan model prediksi ke keputusan, finalkan halaman Streamlit, lakukan
quality assurance dan uji akses publik.
Deliverables yang diserahkan:
1. W15_Full_System_Draft.pdf: desain FIS, membership, rule table, contoh inferensi dan validasi keputusan.
2. Kode pipeline inference (preprocessing + NN + fuzzy), URL Streamlit aktif, requirements, model artifacts, README.
3. Draft laporan lengkap, tabel ablation, screenshot/video uji fungsi serta skenario demo UAS.
Kriteria pemeriksaan: Input baru menghasilkan prediksi dan keputusan; rules konsisten; dashboard dapat dibuka tanpa izin;
repo bebas secret/token.
Minggu 16 - UAS - demo presentasi & pembelaan proyek
Fokus kerja: Presentasikan problem, data, algoritma GA/PSO/NN/FIS, hasil perbandingan dan keterbatasan.
Jalankan demo langsung. Dosen dapat memilih anggota secara acak untuk menjelaskan kode dan keputusan
desain.
Deliverables yang diserahkan:
1. FINAL_Laporan_Tubes_KB_Kelas_Kelompok.pdf serta slide dan video demo (3-5 menit dianjurkan).
2. URL repository final (release/tag disarankan), source, requirements, README, model, config, seed, logs.
3. URL dashboard online dan form kontribusi anggota dengan bukti peran; siapkan cadangan demo lokal bila koneksi
bermasalah.

4. Spesifikasi dashboard Streamlit
Menu / halaman

PSO Optimization

Fuzzy Inference
Membership plots, rule base, output dan penjelasan keputusan.
Prediction / Simulation
Input manual / CSV -> prediksi NN -> keputusan fuzzy.
Model Comparison
Baseline NN vs GA+NN vs PSO+NN vs GA+PSO+NN.
Delapan area ini boleh berupa tabs atau navigation pages; bukan wajib delapan file Python. Proses optimasi berat boleh
dieksekusi offline, tetapi inference di dashboard harus benar-benar berfungsi.
5. Standar evaluasi dan integritas eksperimen
Aspek
Kewajiban
Klasifikasi
Accuracy, precision, recall, F1-score, confusion matrix; bahas imbalance bila relevan.
Regresi/time series
MAE, RMSE, R², actual vs predicted; analisis kesalahan dan urutan waktu.
GA/PSO stokastik
Catat seed, budget evaluasi, konfigurasi, log; jalankan berulang jika feasible dan sajikan statistik.
Pencegahan leakage
Scaler, imputer, seleksi fitur & tuning disesuaikan dengan training/validation saja; test untuk evaluasi
akhir.
Keputusan Fuzzy
Uji rule consistency, skenario ekstrem dan interpretasi; tidak disetarakan dengan akurasi NN.
Reproducibility
Kunci versi library, simpan preprocessing dan model, dokumentasikan jalur menjalankan aplikasi.
